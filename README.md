# Deeper Root In Christ event website

> A beautiful registration website for my spring student retreat.

## Features

- 🌙 Dark/Light mode toggle: Toggle between light and dark themes; preference is saved to `localStorage` for a persistent experience.
- 📝 Easy registration form with validation: Client-side validation with clear error messages; submissions are sent to a Supabase `registrations` table for storage.
- 📱 Fully responsive design: Mobile-first, fluid layouts and responsive typography using modern `clamp()`, `min()`, and `max()` to ensure the site looks great on any screen size.
- 🎨 Beautiful UI: Clean, accessible styling with responsive images and a polished visual hierarchy.
